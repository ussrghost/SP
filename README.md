# Вектор Сенсор

Адаптивный сайт оптового дистрибьютора инерциальных датчиков и промышленных энкодеров. Готовый статический сайт без сборки, внешних библиотек, шрифтов, аналитики или серверных зависимостей.

## Просмотр

Откройте `dist/index.html` в браузере, либо запустите из корня репозитория:

```sh
python -m http.server 8000 --directory dist
```

Перейдите на http://localhost:8000. Для обычного хостинга загрузите **содержимое** папки `dist` в корневую папку сайта.

## Файлы

- `dist/index.html` — все тексты, разделы, характеристики и векторные схемы принципов работы.
- `dist/styles.css` — адаптивное оформление для компьютеров и телефонов.
- `dist/app.js` — выбор направления и сохранение запроса на подбор в текстовый файл.
- `dist/assets/sensors.webp` — сгенерированная иллюстрация условных приборов.

## Что работает

Навигация по разделам, подбор категории из карточки, обязательные поля и проверка email, скачивание запроса UTF-8. Данные обрабатываются только в браузере; отправки по почте, CRM и серверного хранения нет. Никаких API-ключей не требуется.

## Перед коммерческим использованием

«Вектор Сенсор», QINOVA MOTION, ROTAVIQ ENCODER, серии QM-I60/QM-T20/RE-A58/RE-I40 и их параметры придуманы для шаблона. Изображения не являются фотографиями реальных изделий. Обозначение эксклюзивного представительства не подтверждено: замените демонстрационный блок реальными брендами и согласованными условиями. Подбор аналога требует проверки ТЗ и испытаний; взаимозаменяемость не гарантируется.

Замените название компании, бренды, параметры, изображения и сведения о представительстве. Добавьте реальные контакты. Для приёма заявок подключите серверный обработчик, уведомления и применимые условия обработки персональных данных; затем измените тексты формы. Уберите демонстрационные примечания только после замены вымышленного содержания.

## Публикация

Сайт сохранён в репозитории. Публикация на домене отдельно не настроена. Подходит для любого статического хостинга, включая GitHub Pages (артефакт/папка публикации — `dist`). Компиляция и EXE не нужны.
